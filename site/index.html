System boundaries

Keep responsibilities distinct

FSM_COS composes trusted MicroBundles. FSM_API provides state/context execution primitives. ServerApp hosts and operates server roles. A successful composition is not proof of a healthy service.

Artifacts retain BundleId + Version + ContentHash identity. Manifests are declarative—not arbitrary shell or code-loading instructions.

Not yet claimed

What this page does not represent

This is a static documentation and evidence surface. It does not connect to a live server fleet, provision cloud resources, expose a control API, or report real-time service health.

Distributed placement, dependency orchestration, authentication, persistent state, horizontal scaling, client I/O routing, rendering transport, and production deployment remain separate proof milestones.
