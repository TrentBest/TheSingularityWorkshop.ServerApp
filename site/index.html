The Workshop stack

Different jobs.
One system.

ServerApp is not a replacement for the runtime or the state engine. It is the host and fleet layer that gives composed software somewhere to live.

Runtime composition

FSM_COS builds the runtime.

Trusted MicroBundles are resolved and composed into a runtime. The runtime composition manifest describes what software is assembled—not where a server process runs.

FSM_APIState executionFSM_COSCompositionMicroBundlesCapabilities
Runtime composition and server-role provisioning are distinct contracts. Keep their manifests separate.
Operational hosting

ServerApp gives it a home.

ServerApp validates a role declaration, resolves dependencies, plans capacity, and coordinates explicitly registered role adapters. Hosting becomes a separate operational concern.

ManifestDeclarePlannerPlaceAdapterActivate
Current placement is a deterministic plan, not a hardware reservation or distributed scheduler.

A contract, not a command

Say what you need.
Not how to run a shell.

Role manifests describe identity, dependencies, and resource requirements. They do not carry arbitrary commands, executable payloads, or permission to load untrusted code.
